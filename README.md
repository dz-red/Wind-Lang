# Wind

Собственный язык программирования. Транспилируется в C, собирается системным `gcc` — на выходе нативный бинарник со стартом около 2 мс.

Компилятор написан с нуля на чистом Си, около 3500 строк. Никаких генераторов парсеров, никаких сторонних зависимостей кроме `libcurl` для HTTP.

## Как выглядит

Веб-сервер с маршрутизацией — целиком:

```wnd
dict[str,str].info
info["lang"] = "Wind"

http.serve 8080
    on "/"     -> "<h1>Wind web server</h1>"
    on "/json" -> json.encode(info)
    on "/time" -> str(time.now())
end
```

Функции, словари и интерполяция строк:

```wnd
global str.app = "Wind"

func square(int.x) -> int
    return int.x * int.x
end

int.n = 7
dict[str,str].info
info["lang"] = str.app

terminal.paste -> "${str.app}: квадрат ${int.n} равен ${square(int.n)}"
terminal.paste -> "json: ${json.encode(info)}"
```

```
Wind: квадрат 7 равен 49
json: {"lang":"Wind"}
```

## Как устроено

```
файл.wnd
   ↓  lexer.c        разбор на токены, переводы строк значимы
   ↓  astparse.c     построение дерева
   ↓  astcodegen.c   генерация C-кода
output.c
   ↓  gcc -O3 -lm -lcurl
./app
```

Типы объявляются перед именем: `int.x`, `str.name`, `dict[str,int].cfg`. Блоки закрываются явно: `end if`, `end while`, `end loop`, у функций просто `end`. Интерполяция — `${...}`, внутри допускается любое выражение, включая вызов функции.

## Что язык не умеет

Нет ООП, нет лямбд, нет многопоточности и async. Коллекции однотипные: `[1, "hello"]` не соберётся. `int` 32-битный. Сборка только под Linux.

## Известные баги

Проверено на текущей сборке, не исправлено:

- **`try`/`catch` и `throw` не компилируются.** Лексер и парсер их понимают, узлы `ST_TRY`/`ST_THROW` строятся, но кодоген выдаёт `this statement is not supported yet`. Осталось от перехода на AST-пайплайн.
- **`loop` пропускает каждый второй элемент.** На списке `[1,2,3]` печатает `1` и `3`.
- **Литерал списка из двух элементов не собирается**: `int.list.a = [1,2]` → `expects a [..] literal`. С тремя и больше работает.
- **Импорта модулей нет** ни в лексере, ни в парсере, хотя в `LANGUAGE.md` под него есть раздел.

## Сборка

```sh
git clone https://github.com/dz-red/Wind-Lang.git
cd Wind-Lang
make                    # получаем ./wind

./wind file.wnd         # собрать в ./app
./wind -s file.wnd      # собрать и сразу запустить
```

Зависимости: `gcc`, `make`, `libcurl-dev`.
