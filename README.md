# Wind

Собственный язык программирования. Транспилируется в C, собирается системным `gcc` — на выходе нативный бинарник со стартом около 2 мс.

Компилятор написан с нуля на чистом Си, около 3500 строк. Никаких генераторов парсеров: свой лексер, рекурсивный спуск, своя кодогенерация.

## Как выглядит

Веб-сервер с маршрутизацией — целиком:

```wnd
dict[str,str].info
info["lang"] = "Wind"

http.serve 8080
    on "/"     -> "<h1>Wind web server</h1>"
    on "/json" -> json.encode(info)
    on "/time" -> str(time.now())
end
```

Функции, словари и интерполяция строк:

```wnd
global str.app = "Wind"

func square(int.x) -> int
    return int.x * int.x
end

int.n = 7
dict[str,str].info
info["lang"] = str.app

terminal.paste -> "${str.app}: квадрат ${int.n} равен ${square(int.n)}"
terminal.paste -> "json: ${json.encode(info)}"
```

```
Wind: квадрат 7 равен 49
json: {"lang":"Wind"}
```

## Как устроено

```
файл.wnd
   ↓  lexer.c        разбор на токены, переводы строк значимы
   ↓  astparse.c     построение дерева
   ↓  astcodegen.c   генерация C-кода
output_ast.c
   ↓  gcc -O2 -lgc -lm
./app
```

Типы объявляются перед именем: `int.x`, `str.name`, `dict[str,int].cfg`. Блоки закрываются явно: `end if`, `end while`, `end loop`, у функций просто `end`. Интерполяция — `${...}`, внутри допускается любое выражение, включая вызов функции.

## Что язык не умеет

Нет ООП и классов, нет импорта модулей, нет лямбд, нет многопоточности и async. Коллекции однотипные: `[1, "hello"]` не соберётся. `int` 32-битный. Сборка только под Linux.

## Подводные камни

- Запятая — десятичный разделитель (`3,14`), поэтому в литералах списков нужен пробел после неё: `[1, 2, 3]`, иначе `[1,2,3]` прочитается как `[1.2, 3]`.
- Остаток от деления — оператор `/%`, не `%`.
- Тип пишется только при объявлении: `int.x = 5`, дальше `x = x + 1`.
- `.len` у строк считает байты, не символы.

## Сборка

```sh
git clone https://github.com/dz-red/Wind-Lang.git
cd Wind-Lang
make                    # получаем ./wind

./wind file.wnd         # собрать в ./app
./wind -s file.wnd      # собрать и сразу запустить
```

Зависимости: `gcc`, `make`, `libgc` (Boehm GC), `libcurl`.
