# 🍃 Wind Language Support

Syntax highlighting and file icons for the **Wind** programming language.

## Features
* 🎨 Full syntax highlighting (`.wnd` files)
* 🌊 Custom ocean-breeze file icon
* ⚡ Lightweight and fast

## Commands
* `wind -s <file.wnd>` — Compile and run your code instantly
